# MDM Backup Library

Ye folder MDM backup library hai.

- Har model ka apna subfolder banta hai — masalan `mdm-backups/<model>/`.
- **Proinfo Backup** op yahan `.bin` file ke saath `.json` note rakhta hai (kis phone se, kab, kitni bari file).
- Saaf (MDM-free) phone ka backup hi kal kisi aur phone ki madad karega — is liye har model ka pehla backup kisi saaf phone se lo aur mehfooz rakho.
- Kisi model ka patch pehle se andar NAHI hai — library tumhare apne counter tajurbe se bharegi, waqt ke saath.
- Files kahin share karne se pehle soch samajh kar share karo — in me customer ka data ho sakta hai.
