# tools/ — engine folder

Tool apne engines yahan dhoondhta hai (na hon to PATH par dhoondhta hai,
phir bhi na milen to operation ke log me saaf "engine setup required"
aata hai — crash kabhi nahi):

- `platform-tools/adb.exe`, `platform-tools/fastboot.exe`
  (Google platform-tools, free)
- `mtkclient/` — MTKClient (open-source) ki copy, ya system `mtk` command
- `loaders/qualcomm/<brand>/` — Hamza ke apne firehose loaders
  (EDL operations inhin par chalengi; koi loader bundle NAHI kiya gaya)
