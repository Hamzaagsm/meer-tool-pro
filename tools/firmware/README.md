# tools/firmware/ — MTK scatter firmware yahan rakho

MTK "Flash Firmware (Scatter)" operation yahan se firmware parhti hai:
stock firmware ka POORA folder yahan rakho — scatter file
(MTxxxx_Android_scatter.txt jaisi) aur us ke saath wali tamam .img/.bin
files aik hi jagah hon.

Ghalat firmware flash karne se phone brick ho sakta hai — hamesha
pehle "Full Backup" operation se backup lo.
